# Password Security Authentication Simulator (P.A.S.S.)

This repository is my personal portfolio version of a team project originally developed at Florida Polytechnic University.

The application is a Python desktop simulator focused on password security concepts, including password creation, strength evaluation, hashing, stored-password analysis, and brute-force attack simulation.
